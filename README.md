# FilaCerta

O Fila Certa é um protótipo de site para organizar o atendimento em serviços públicos de Palmares/PE. A pessoa escolhe o serviço, seleciona um horário disponível, informa o nome e recebe um comprovante do agendamento. Com isso, o site ajuda a organizar a demanda: os horários ficam distribuídos ao longo do dia, a população sabe com antecedência onde e quando será atendida, e os órgãos conseguem se planejar melhor para receber as pessoas. A ideia é evitar filas longas e manhãs perdidas. Todos os serviços e dados são fictícios
